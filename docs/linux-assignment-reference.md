第 3 次作业（第 10 周后）：导航引擎集成、语音与存储 / 定位适配
任务内容：
集成导航状态机： idle/ 规划中 / 导航中 / 偏航 / 到达状态管理
实现语音适配（ LinuxVoiceAdapter ）： speak() 调用本地 TTS 、 listen() 调用本地 ASR ，设
置中文语言环境，处理语音回调并通过 FFI 传回核心层，注意语音服务生命周期管理
实现存储 / 定位适配（ StorageAdapter/LocationAdapter ）：存储用 SQLite 和本地文件系
统，定位用 GeoClue2 ，声明 LOCATION/MICROPHONE 权限，离线数据包随应用分发
实现导航 UI ：地图视图（ Qt/OpenGL 渲染） / 导航仪表盘（速度 / 剩余距离 / 转向提示） /
引导指令显示
实现偏航检测与重算：基于定位和地图匹配结果检测偏航，自动重算路径
开发模拟导航功能：模拟 GPS 轨迹驱动导航过程，可暂停 / 加速 / 回放
