## Qt Kit 与验证

Kit：`P1 Linux - Qt 6.4.2 - GCC 13.3.0`。
Qt qmake：`/usr/bin/qmake6`；C 编译器：`/usr/bin/gcc-13`；C++ 编译器：`/usr/bin/g++-13`；CMake：`/usr/bin/cmake`；调试器：`/usr/bin/gdb`；生成器：Ninja；C++17；`CMAKE_PREFIX_PATH=/usr`。Qt Creator 正确读取 Kit，配置页无 Kit 警告。

独立检查源码位于来宾 `~/environment-check/`，与导航业务代码分开。CMake 使用 `find_package(Qt6 6.4.2 EXACT REQUIRED COMPONENTS Widgets)`，并显式指定 GCC/G++ 13。复核命令：

```bash
cd ~/environment-check
cmake -S . -B build -G Ninja -DCMAKE_C_COMPILER=/usr/bin/gcc-13 -DCMAKE_CXX_COMPILER=/usr/bin/g++-13
cmake --build build
./build/p1-environment-check --smoke
```

结果：CMake 配置/编译通过，无显示窗口 smoke 运行通过，Qt Widgets 窗口在 Ubuntu Wayland 桌面实际显示；Qt Creator 配置同一工程并执行构建，Compile Output 显示 `/usr/bin/cmake` 正常退出。IDE 构建截图中的 27 秒仅为单次环境检查耗时，不是导航性能指标。
