# 五人职责提示词

选择一段附在通用开场后，具体环境、接口与进度以 project.md 为准。以下路径均为规划位置，使用前确认实际工程结构。

## 1 号：应用框架、语音与发布

```text
按 1 号职责处理本次目标：Qt 窗口/页面/主布局/主题、公共 UI、顶层 CMake、用户页面、LinuxVoiceAdapter 与发布分发。只推进我指定的子任务。
先与其他模块约定最小契约，避免把所有人的业务实现塞进应用入口。数据持久化通过 2 号接口，导航事件通过 4 号接口，地图展示使用 5 号 LinuxRenderer。
若本次是语音：覆盖本地中文 TTS/ASR、speak()/listen()、经 FFI 返回核心层的回调；明确 ABI、回调线程、数据所有权和销毁顺序，验证麦克风拒绝访问、停止/重复启停与退出。X09 涉及 G10/本地语音方案，不能把 TTS 当作 ASR 完成。
若本次是发布：验证完整 CMake 工程、Linux 可执行程序、运行依赖、离线包随应用分发及新环境启动步骤；不要仅凭 Windows 编译结果宣称 Linux 可交付。
```

## 2 号：数据、存储与离线包

```text
按 2 号职责处理本次目标：导入、StorageAdapter、SQLite/本地文件、离线包与用户本地数据。相关规划位置 src/data/ 与 src/pal/linux/storage/。
X01 对应 G1 格式；X07 对应 G7 包方案；X02/X03 只有真实需要时才直接接入。未确认接口先展示选择，使用 Mock 时标清替换点。
先定义只读数据与存取契约，独立样例使用小型路网/POI/轨迹和临时数据库。导入验证正常、坏文件、取消及进度展示；存储验证事务、持久化和错误恢复；离线包验证版本/校验、下载/更新失败、重启后状态与离线读取。
向 1 号提供用户数据接口与资源分发清单，向 3/5 号提供统一数据与坐标约定，避免调用方直接访问内部表或全量复制大数据。根据本次范围选择必要测试。
```

## 3 号：算法集成与性能

```text
按 3 号职责处理本次目标：C++ A*/HMM、公共计算契约、数据转换、后台任务、算法调用页和性能监控。相关规划位置 src/algorithms/。
核实 X04/X05 的真实源码、输入输出、构建依赖、来源及线程安全；X02/X03 仅为条件依赖。C++ 本地集成，不沿用旧平台 NAPI 方案。
路径与匹配结果由确定性图/轨迹验证，标明样例来源、坐标、单位、路径质量或误差。验证无路可达、空/无效输入、取消、旧结果回流、并发和资源释放；耗时任务不阻塞 UI。
需要算法选型时先走组合比较流程，真实 A*/HMM 不能用固定路线或最近邻 Mock 冒充。将算法结果与 5 号渲染接口和 4 号导航接口对接，不直接修改其内部状态。
```

## 4 号：定位、导航与 G6 联调

```text
按 4 号职责处理本次目标：LocationAdapter/GeoClue2、权限、状态机、偏航重算、模拟定位、暂停/加速/回放及 G6 联调报告。相关规划位置 src/navigation/ 与 src/pal/linux/location/。
先用固定事件/轨迹和可替换位置源独立验证，再接真实服务。覆盖 idle/规划中/导航中/偏航/到达与暂停相关转换，明确拒绝权限、位置丢失、计算失败、停止后回调与重算去重。
X06 必须确认 G6 的事件、状态、PAL/FFI 边界和版本。调度 3 号计算，向 5 号发布快照，向 1 号发布引导并处理语音命令；保持线程/资源归属清晰。
第 4 次 G6 报告必须来自真实双方联调；Mock 只能验证本地契约。用例记录输入、预期、实际、版本、环境、缺陷和复测，不把本地状态机测试写成跨组已联调。
```

## 5 号：渲染与导航展示

```text
按 5 号职责处理本次目标：LinuxRenderer、地图瓦片/路线/标记、交互、仪表盘与引导显示。相关规划位置 src/pal/linux/renderer/ 与 src/ui/map/。
先核实 Qt Widget/OpenGL ES 路线及当前环境；需要选型时展示组合与一次忽略选项。X08/G8 为条件依赖，外部渲染程序不能替代本组 PAL 适配。
以固定 MapScene/NavigationSnapshot 建立可独立运行的演示，落实 drawTile→drawImage、drawRoute→drawLine、present→flush 映射；明确异步绘制、上下文归属、线程切换与资源释放。
展示速度/剩余距离/转向信息，但不在渲染层重复实现导航判断。验证输入更新、缩放/平移/跟随、空数据、退出和上下文错误；在真实目标环境记录帧率、内存、响应时间与场景规模，不虚构达标阈值。
```
