# P1 鸿蒙导航项目

5 人协作开发 HarmonyOS 导航 App，使用 ArkTS / ArkUI 与 C++ Native 模块。

当前阶段：完成团队规划与 AI 协作规则，尚未创建可运行的鸿蒙工程。

## 开始工作

1. 阅读 [AGENTS.md](AGENTS.md)，向 AI 说明自己的组员编号（1–5）及本次任务。
2. 阅读 [project.md](project.md)，确认环境、模块归属、进度和跨组接口决策。
3. 查看 [任务书摘录](docs/assignment-reference.md) 与 [AI 对话日志](ai_log.md)。
4. 在个人分支开发；完成模块时同步更新 `project.md`，每轮对话追加 `ai_log.md`。

推荐开场：`我是 P1 组员 3。请先阅读 AGENTS.md、project.md 和 ai_log.md，再处理我的 Native 桥接任务。涉及跨组接口时先说明选项，等待我选择。`

支持 `AGENTS.md` 的 AI 工具应读取根目录规则；其他工具请手动附加上述文件或将这句话设为项目启动提示。仓库文件不能保证所有 AI 客户端自动加载规则，也不能在客户端未提供对话时自动获取聊天记录。

环境版本及构建步骤见 `project.md`。尚无可执行构建命令或 HAP，请勿将文档完成理解为应用已完成。
